# Miniproyecto Geant4: Simulación de Lluvias de Partículas Atmosféricas

Este repositorio contiene la configuración Docker y el código fuente en Geant4 para la simulación de lluvias de partículas atmosféricas producidas por rayos cósmicos.

## 1. Descarga de la Imagen Docker Hub

La imagen pública está alojada en Docker Hub. Para descargarla ejecuta:

```bash
docker pull tu-usuario-docker/geant4-cosmic-showers:latest
